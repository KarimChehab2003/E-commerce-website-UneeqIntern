# 🛍️ E-commerce Website

A sleek and responsive e-commerce website built with **React**, **Vite**, and **Tailwind CSS**. This project allows users to browse products, add items to a shopping cart, and proceed to checkout.

## ✨ Features

- 🧾 Product listing with dynamic data rendering
- 🔍 Product search and filtering
- 🛒 Add/remove items from the cart
- 📦 View cart with item details and total cost
- 🎨 Responsive and modern UI using Tailwind CSS

## 🔧 Tech Stack

- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
